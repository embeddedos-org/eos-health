📖 Overview

The EoS Health API provides programmatic access to health data collected by all four EoS Health devices. It is designed for developers building fitness apps, clinical research tools, chronic disease management platforms, and enterprise wellness solutions.

ℹ️
The sandbox environment at sandbox.api.eoshealth.io returns realistic synthetic data for all endpoints — no physical device required for development.

Supported Devices

DeviceUnique DataCommon Data
HEALTH-KEY ULTRABAC (breath alcohol), UV index, USB-HID modeECG, SpO₂, HR, HRV, sleep, activity
HEALTH-BAND Neuro8-channel sEMG, EDA/stress, TENS sessionsECG, SpO₂, HR, HRV, sleep, activity
HEALTH-RING UltraHbA1c (NIR), cuffless BP, 5λ PPGECG, SpO₂, HR, HRV, sleep, activity
HEALTH-LAB UltraGlucose, lactate, cortisol, K⁺, Na⁺, pH, uric acidHR, activity, patch lifetime
⚡ Quickstart

Get your first health data in under 5 minutes.

Python
# pip install eos-health
from eos_health import EosHealthClient

# Initialize with your access token
client = EosHealthClient(access_token="eos_at_your_token_here")

# Get today's recovery score
recovery = client.recovery.get(start_date="2026-06-01")
for day in recovery["days"]:
    print(f"{day['date']}: Recovery {day['score']}/100 ({day['category']})")

# Get AFib detection from ECG
ecg = client.ecg.get(start_date="2026-06-01")
for rec in ecg["recordings"]:
    if rec["afib_detected"]:
        print(f"⚠️ AFib detected at {rec['timestamp']} (confidence: {rec['afib_confidence']:.1%})")

# Get continuous glucose (HEALTH-LAB)
glucose = client.glucose.get(start_date="2026-06-01")
for reading in glucose["data"]:
    print(f"{reading['timestamp']}: {reading['glucose_mgdl']} mg/dL ({reading['trend']})")
JavaScript
// npm install @eos-health/api
import { EosHealthClient } from '@eos-health/api';

const client = new EosHealthClient({ accessToken: 'eos_at_your_token_here' });

// Get recovery scores
const recovery = await client.recovery.get({ startDate: '2026-06-01' });
recovery.days.forEach(day => {
  console.log(`${day.date}: ${day.score}/100 (${day.category})`);
});

// Get HbA1c (HEALTH-RING Ultra)
const hba1c = await client.hba1c.get({ startDate: '2026-06-01' });
hba1c.data.forEach(r => {
  console.log(`HbA1c: ${r.hba1cPct}% (${r.hba1cMmol} mmol/mol)`);
});

🔐 Authentication

The EoS Health API uses OAuth 2.0 Authorization Code flow. Users authorize your application, and you receive an access token to make API calls on their behalf.

OAuth 2.0 Scopes

ScopeAccess
read:healthAll health metrics (HR, ECG, SpO₂, glucose, sleep, activity, recovery)
read:devicesDevice list, firmware version, battery status
read:userUser profile and email
write:webhooksCreate and delete webhooks
read:ecg_waveformRaw ECG waveform data (requires explicit user consent)
Authorization URL
https://api.eoshealth.io/v1/oauth/authorize
  ?client_id=YOUR_CLIENT_ID
  &redirect_uri=https://your-app.com/callback
  &scope=read:health read:devices read:user
  &state=random_csrf_token
  &response_type=code

🔔 Webhooks

Webhooks deliver real-time event notifications to your server. EoS Health signs every webhook payload with HMAC-SHA256 using your webhook secret.

Available Events

EventTriggerDevice
afib.detectedAFib rhythm detected in ECGAll
glucose.alertGlucose outside normal rangeHEALTH-LAB
glucose.criticalGlucose critically low/highHEALTH-LAB
spo2.alertSpO₂ drops below 90%All
blood_pressure.alertBP exceeds hypertension thresholdHEALTH-RING Ultra
heart_rate.alertHR exceeds user-defined thresholdAll
device.syncDevice synced new dataAll
device.low_batteryBattery below 15%All
device.ota_availableNew firmware availableAll
Webhook Signature Verification (Python)
import hmac, hashlib

def verify_webhook(payload: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(secret.encode(), payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)

📈 ECG
GET /v1/ecg Get ECG recordings with AFib detection

Returns ECG recordings with automated analysis including AFib detection (AUC=0.998), QRS/QT/PR intervals, and HR. Available on all 4 EoS Health devices.

Required scope: read:health · Raw waveform requires read:ecg_waveform

⚠️
AFib detection is for wellness monitoring only and is not a medical diagnosis. Users should consult a physician for any cardiac concerns.

🔋 Recovery
GET /v1/recovery Get daily recovery scores (0–100)

Recovery score combines HRV, resting HR, sleep quality, respiratory rate, and skin temperature. Comparable to Whoop Recovery Score but uses more data sources.

🩸 Glucose
GET /v1/glucose Continuous glucose monitoring (HEALTH-LAB)

Returns continuous glucose readings every 5 minutes from HEALTH-LAB patch. ISO 15197 compliant — 100% Zone A accuracy in clinical validation.

Requires: HEALTH-LAB device · read:health
